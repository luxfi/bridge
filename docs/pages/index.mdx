## What is Lux Bridge?

The Lux Bridge enables:

- **Secure asset transfers** — move tokens between 15+ chains with 2-of-3 threshold signatures
- **Multi-Party Computation** — distributed key generation, no single point of failure
- **Post-quantum-safe option** — lattice-based MPC protocols (`pulsar`, `corona`, `magnetar`)
- **Optional layered cosigners** — Utila or Fireblocks on top of native MPC
- **Universal message passing** — arbitrary cross-chain messages, not just token transfers
- **Low fees & fast finality** — competitive bridge fee with caps, minutes not hours

## Getting Started

The bridge ships as a single Go binary (`cmd/bridge`) that embeds the SPA and
serves both the UI and the native `/v1/bridge/*` API on one port.

```bash
# Pull and run the unified bridge image
docker run --rm -p 8080:8080 \
  -v $(pwd)/networks.yaml:/etc/bridge/networks.yaml \
  ghcr.io/luxfi/bridge:latest
```

Visit [http://localhost:8080](http://localhost:8080) for the bridge UI; the
native API is at [http://localhost:8080/v1/bridge](http://localhost:8080/v1/bridge).

For SDK consumers (Lux, Hanzo, Zoo, white-label tenants), import the public
`@luxfi/bridge` package and call `mountBridge(...)` — see the [`pkg/bridge`
README](https://github.com/luxfi/bridge/tree/main/pkg/bridge) for tenant usage.

For local dev (workspace install, watcher fleet, tenant SPAs), see the top-level
[`README.md`](https://github.com/luxfi/bridge/blob/main/README.md).
